# 🍽️ Fine Dining Set Menu & Launching Simulator

Interactive financial and inventory planning simulator designed for Fine Dining restaurant launches and culinary capstone projects.

### Key Features:
1. **Set Menu Ingredient & Stock Planner:** Calculates Cost of Goods Sold (COGS / HPP) per portion across a 6-course set menu (Appetizer, Salad, Soup, Main Course, Dessert, and Beverage) and determines maximum serving capacity.
2. **Smart Menu Pricing Recommendation:** Automatically suggests optimal selling prices based on industry-standard **25%–30% Food Cost** targets.
3. **Capstone / Practice Profit & Loss Analysis:** Simulates net profit or loss for academic pop-up operations based strictly on ingredient expenditure and customer volume.
4. **Commercial Full-Cost Simulation (100% Structure):** Optional breakdown projecting real-world commercial viability factoring in **Labor Cost (30%)**, **Rent & Utilities (12%)**, **Other Expenses (13%)**, and **Target Net Profit (10%)**.
